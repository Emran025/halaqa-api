# سيناريو المحاكاة: حلقة الإتقان اليومية

## الغرض والنطاق

ينشئ الأمر `php artisan db:seed --class=DemoHalaqaSeeder` بيئة تعليمية تجريبية متكاملة داخل **Halaqa API**. الغرض منها اختبار مسارات المعلم والطالب والحلقة والخطة والمتابعة والجلسات والتقارير والإشعارات ببيانات مترابطة قابلة لإعادة التشغيل. هذه البيانات مصنفة بوضوح كبيانات عرض، ولا تنشئ دوراً إدارياً أو مساراً مختلفاً عن الأدوار المعتمدة في النظام.

تستند نطاقات الأجزاء والأحزاب وأنصافها وأرباعها والصفحات إلى بيانات `Tracking_Unit` من مشروع `Emran025/shafeea_teach` ذي ترخيص MIT، عند الالتزام `c19b15cd82dcbeeeb66d1f000c9d0f6a7e5356d9`. تحفظ البيانات المرجعية محلياً في `database/seeders/data/quran_range_units.json`، لذلك لا يحتاج Seeder إلى اتصال شبكي أثناء التشغيل.

## الحلقة والخطة التعليمية

تنشأ حلقة واحدة نشطة باسم **حلقة الإتقان اليومية**، مخصصة للطلاب، في المنطقة الزمنية `Asia/Riyadh` وبسعة اثني عشر طالباً. يرتبط بها ستة طلاب فعالين منذ فترات متدرجة، ليظهر اختلاف النضج والتقدم داخل القائمة.

تشتمل خطة أحمد ياسر الغامدي، وهي الخطة المرجعية الرئيسة للعرض، على ثلاثة بنود مرتبة: **حفظ صفحتين يومياً**، و**مراجعة جزء واحد يومياً**، و**تلاوة ربع حزب مرتين أسبوعياً**. بقية الخطط تراعي اختلاف المستوى ومرحلة الطالب، بدلاً من إعطاء جميع الطلاب هدفاً موحداً غير واقعي. تكون الخطط فعالة ومعتمدة من المعلم، ويجري توليد عناصر متابعة ماضية وحالية وقادمة لها.

## السجل الزمني وميزات العرض

يبنى السجل نسبة إلى تاريخ تشغيل Seeder، ليظل مناسباً للاختبار في أي وقت. يتضمن ثمانية وعشرين يوماً من الحضور المتنوع والحفظ والمراجعة، مع حضور منتظم غالباً، وتأخر أو عذر محدودين، وبنود متابعة مكتملة ومتجاوزة وقادمة. تتضمن السجلات درجات واقعية وملاحظات تربوية قصيرة، وتظهر تقدماً متدرجاً دون ادعاء الكمال.

تنشأ جلسات منتهية موثقة لطالبين، مع مهام حفظ ومراجعة وتقرير معتمد وملاحظات وتقييمات وأخطاء تدريبية محدودة. لا تنشأ جلسة متصلة أو أي محتوى صوتي أو مرئي؛ فبيانات المحاكاة تقتصر على السجل الرسمي ولا توحي بوجود اتصال مباشر فعلي. كما تنشأ جلسة مجدولة قادمة وإشعارات مرتبطة بالخطة والجلسة والتقرير، لإظهار المسارات التشغيلية للواجهات المختلفة.

## خصائص التكرار والأمان

تستخدم جميع سجلات العرض UUIDs ثابتة ومفاتيح تعريفية تبدأ بـ`demo-halaqa-`. يعيد تشغيل Seeder تحديث نفس السجلات أو إنشاء السجلات الناقصة دون إنشاء حسابات أو وحدات أو إشعارات مكررة. يزرع `QuranRangeUnitSeeder` قبل بيانات المحاكاة، ويضمن وجود المصحف المرجعي والنطاقات قبل أي خطة أو سجل متابعة يعتمد عليها.

## تشغيل البيئة التجريبية

بعد ضبط اتصال قاعدة بيانات API وتشغيل الترحيلات، استخدم الأمر التالي:

```bash
php artisan db:seed --class=Database\\Seeders\\DemoHalaqaSeeder
```

لتجهيز قاعدة بيانات جديدة من البداية، نفّذ أولاً:

```bash
php artisan migrate:fresh --seed
```

ثم شغّل Seeder المحاكاة بالأمر الأول أعلاه. لا تشغّل `migrate:fresh` على قاعدة بيانات تحتوي بيانات مستخدمين حقيقية لأنه يعيد إنشاء الجداول.
